# First session note guide

This guide is loaded only while no valid dated session note exists. Create the first note using the current UTC date, for example `2026-07-19.md`, and update it incrementally throughout the conversation.

The note should preserve what a future conversation needs to understand this encounter: why the user came, what mattered in the discussion, relevant context and impact, patterns or hypotheses considered, interventions or reflections and the user's response, meaningful risk or protective information, decisions, unresolved questions, and the next direction. Include only the elements that were actually relevant.

For a first session, clarify essential context gradually and naturally. Do not interrogate the user in order to complete the record. Write a coherent summary rather than a transcript, distinguish the user's account from observations and tentative formulations, and choose headings only when they improve readability.

Maintain the note while the session develops. At a natural endpoint, record the resulting direction and treat the note as historical context rather than continually rewriting it during later sessions.
