# First session note guide

This guide is loaded only while no valid dated session note exists. Create the first note using the current UTC date, for example `2026-07-19.md`, and update it incrementally throughout the conversation.

Use the following structure when clinically relevant; omit empty sections rather than inventing information.

```markdown
# Session note

**UTC date:** YYYY-MM-DD
**Status:** Ongoing | Complete

## Reason for contact and priorities

## Patient-reported information

## Functioning and impact

## Observations

## Patterns and working hypotheses

## Interventions or reflections and patient response

## Risk and protective information

## Decisions and agreed actions

## Unresolved questions

## Next step
```

For a first session, gradually clarify the reason for seeking help, time course, variability, functional impact, previous support or treatment, current supports, goals, and safety information when relevant. Do not ask everything at once.

Write a clinical summary, not a transcript. Separate the patient's account from observations and hypotheses. Mark the note complete at a natural session endpoint, preserve it as historical context, and place later developments in a new dated note.
