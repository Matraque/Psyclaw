# Patient record references

This file is the stable index and record-keeping guide for the patient folder. Keep it concise and update the index only if the folder structure changes.

## Canonical records

- `references.md` — this index and the shared record-keeping conventions.
- `patient_profile.md` — stable factual context that may affect future support.
- `memory.md` — the concise, current longitudinal clinical synthesis.
- `care_plan.md` — agreed goals, active work, progress markers, and next steps.
- `session_notes/` — dated records of individual consultations.
